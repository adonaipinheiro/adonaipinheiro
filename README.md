# Oi, eu sou o Adonai 👋

Moro em São Paulo, trabalho com arquitetura no grupo **GOL / Smiles** e dou aula na pós-graduação da **FIAP** e da **USP/Esalq**.

No trabalho, meu dia é decidir como sistemas grandes conversam entre si: arquitetura mobile, IA aplicada, e a longa travessia de apps nativos para uma base compartilhada em React Native. Na sala de aula é a mesma coisa em escala menor — e com perguntas melhores.

> **Tecnologia é um meio.** Escolher a stack é a parte fácil. O difícil é entender o problema de verdade e deixar algo que o próximo time consiga levar adiante sem mim.

### O que tem por aqui

Boa parte dos repositórios deste perfil é material de aula — código escrito para ser lido e destrinchado, não para rodar em produção. Se você chegou aqui vindo de uma aula, provavelmente é isso que está procurando. O **[USPMovies](https://github.com/adonaipinheiro?tab=repositories&q=USPMovies)** é meu preferido do gênero: o mesmo app feito três vezes, em React Native, Swift e Kotlin, para a gente comparar as escolhas lado a lado.

O resto nasceu de problemas reais, como o **[signature-touch](https://github.com/adonaipinheiro/signature-touch)** — uma lib enxuta de captura de assinatura para React Native.
